A simulation is a set of assumptions

Test the numerical behavior. Keep the scientific judgment yours.

Siphon examines existing Python code. It does not rewrite your model or certify that its assumptions describe the real world. Its job is to make the checks and their evidence easier to inspect.

The review

Three steps. Each one reviewable.

You stay in control of the scientific context. Siphon records what it understood and asks when a consequential detail is missing.

What a check can tell you

Useful evidence. Bounded claims.

A numerical check can reveal behavior in the code under stated conditions. It cannot, by itself, prove that a model is implemented correctly for every purpose or that its physics match reality.

  • No universal correctness score
  • No silent assumptions or missing-data passes
  • No generated replacement simulation code
  • Uncertainty and exclusions shown with the result
